Checkpoint 1:
  Bug:
    The Interrupts were not being called as expected.
  Resolution:
    The macro for exception IDTs were using the wrong values for the reserved bits. 
    Updating the macro fixed the issue.

  Bug:
    The order of the registers in the exception handlers was incorrect:
  Resolution:
    Moving error code to between the registers and the saved return value
  
  Bug:
    Code was failing the IDT Test, causing an exception 
    (that was not handled as it used a non-standard exception) 
  Resolution:
    Code was checking if the IDT was empty for entries 0-9. 
    Entry 1 is reserved, so it was not being set.
    Changing the test to ignore this entry solved the issue.

  Bug:
    RTC was not sending interrupts, and the keyboard caused a #GP exception
  Resolution:
    The wrong bit was IRQ was being unmasked in init_pic,
     causing the keyboard to be unmasked and the slave to be masked. 
     Changing the mask from xFD to xFB correctly unmasks the slave.

  Bug:
    For-loop decleration causing make errors ("loop initial decleration 
    used outside c99 mode")
  Resolution:
    Had to declare looping variable outside of for-loop

  Bug:
    Keyboard input showing up but fails in 3 ways: 1)Wrong char showing
    2)sometimes more than 1 char being shown for a single keystroke
    3)some keys that should be usable are causing a general_protection
    interrupt
  Resolution:
    1)Did not map the letter "e" causing offsets to be wonky
    2)Bounds checking within if/else if statements for scancode check
    3)Because of the wonky offsets from 1), invalid scancodes tranlsation
    led to unwanted behaviors hence general protection fault via invalid
    memory address

  Bug:
    Attempting to start paging crashed the kernel, returning to the bootloader.
  Resolution:
    1. VIDEO_MEM_INDEX was already set to the index in the table, no need for bitshift
    2. video mem address needed to be bitshift 12 before being put in table
    3. Mixed uint32_t and uint8_t in the types was causing the 4mb directory element
       to be 5 bytes long, breaking the entire table.
